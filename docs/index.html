Installing

On Windows
  1. Open the file you downloaded.
  2. Windows may say Windows protected your PC. This is because the app isn't signed yet. Click More info, then Run anyway.

    Windows protected your PC

    Microsoft Defender SmartScreen prevented an unrecognised app from starting.

    App: Superdesk-windows-x64-setup.exe
    Publisher: Unknown publisher

    Run anyway Don't run
  3. Superdesk installs and opens by itself.
On Linux
  1. Allow the file to run. In your file manager, right-click it, open Properties and turn on Allow executing file as program. Or in a terminal: 
    chmod +x Superdesk-linux-x86_64.AppImage
  2. Double-click the file to open Superdesk.
  3. If nothing happens on Ubuntu, install the library AppImages need, then try again: 
    sudo apt install libfuse2t64
    On Ubuntu 22.04 the package is called libfuse2.

First start

Superdesk asks for your company's Superdesk address, such as desk.yourcompany.com. It's the address you use to open Superdesk in your browser. If you're not sure, ask your IT team.

When a new version is out, Superdesk offers it in the sidebar. To check yourself, open Help and choose Check for updates.
