# Superdesk desktop releases

Installers for the Superdesk desktop app. Download the newest version from
the [download page](https://magebitcom.github.io/superdesk-desktop-releases/),
or pick any version from the Releases page.

This repository holds the installers and the download page (in `docs/`)
only. Releases are published automatically, please don't upload files by
hand.
